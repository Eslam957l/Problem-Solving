## Probelm Name: Person Class with Communication Methods
#### Info: 

This program defines a clsPerson class to store and manage personal information such as ID, name, email, and phone.

The class also includes functions to simulate sending emails and SMS messages.
Useful for practicing object-oriented programming (OOP), encapsulation, and class methods in C++.
