## Client Record Update System

This program manages client records stored in a text file and allows updating a client by account number.
It loads all clients into a vector of structs (strInfo) and provides functions to convert lines to records and back.
The program searches for the client, displays the client details, and asks for confirmation before updating.
Users can modify the PinCode, Name, Phone, and Salary of the client. Updated records overwrite the file while keeping other clients intact.
Useful for practicing structs, file handling, vectors, string parsing, and implementing safe update operations.
