## Client Record Deletion System

This program manages client records stored in a text file and allows deleting a client by account number.
It loads all clients into a vector of structs (strInfo) and provides functions to convert lines to records and back.
The program searches for the client, displays the client details, and asks for confirmation before deletion.
Deleted clients are marked in memory, and the file is updated by overwriting it without the marked records.
Useful for practicing structs, file handling, vectors, string parsing, and implementing safe delete operations.
